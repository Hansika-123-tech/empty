# Python Command-Line Calculator

A simple Python command-line calculator.

## Features

This calculator provides basic arithmetic operations:
- **Add**: Adds two numbers together.
- **Subtract**: Subtracts the second number from the first.
- **Multiply**: Multiplies two numbers together.
- **Divide**: Divides the first number by the second.

## How to run

To run the interactive command-line interface, simply execute:

```bash
python main.py
```

## How to run tests

To run the automated tests using the `unittest` framework, execute:

```bash
python -m unittest tests/test_calculator.py
```
